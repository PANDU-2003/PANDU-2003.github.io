## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a new public repository named `PANDU-2003.github.io` (or use another repository and enable Pages).
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. Your site will be available at `https://PANDU-2003.github.io/` after GitHub finishes deployment.
